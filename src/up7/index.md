# 📎 UP7 — Gestión de aplicaciones de ofimática web

Las aplicaciones de ofimática web permiten crear y compartir documentos, hojas de cálculo, archivos, calendarios y tareas desde el navegador. En esta unidad se instalan y se administran dentro de la intranet de una organización.

::: info-box Ficha de la unidad
- **Resultado de aprendizaje:** RA4 — 10 % de la nota del módulo.
- **Duración prevista:** 15 horas.
- **Aplicación de trabajo:** Nextcloud con ONLYOFFICE, con Google Workspace y Microsoft 365 como referencia comparativa.
:::

## Resultado de aprendizaje

**RA4.** Gestionar aplicaciones de ofimática web integrando funcionalidades y asegurando el acceso a la información.

## Criterios de evaluación

| CE | Criterio de evaluación |
|:--:|:-----------------------|
| 4a | Se ha reconocido la utilidad de las aplicaciones de ofimática web. |
| 4b | Se han clasificado según su funcionalidad y prestaciones específicas. |
| 4c | Se han instalado aplicaciones de ofimática web. |
| 4d | Se han configurado las aplicaciones para integrarlas en una intranet. |
| 4e | Se han gestionado las cuentas de usuario. |
| 4f | Se han aplicado criterios de seguridad en el acceso de los usuarios. |
| 4g | Se han utilizado las aplicaciones de forma cooperativa. |
| 4h | Se ha elaborado documentación relativa al uso y gestión de las aplicaciones. |

## Contenidos del currículo

- Tipos de aplicaciones: procesador de textos, hoja de cálculo, gestión de archivos, calendario, citas, tareas, entre otros.
- Instalación.
- Configuración.
- Integración de aplicaciones heterogéneas.
- Gestión de usuarios.
- Control de accesos.
- Aseguramiento de la información.
