## El proyecto del portal interno

La P4.1 cierra el proyecto del [portal interno con WordPress](/up2/ejercicios/) y completa su manual de usuario.

::: tip-box Antes de empezar
Repasa el [ejemplo guiado de Code Snippets](../contenidos/2-ejemplo-code-snippets) para la P4.1, y el tema de [adaptación de gestores de contenidos](../contenidos/1-adaptacion-cms) para la P4.2 y la P4.3.
:::

## Cómo se evalúan

Cada práctica tiene su rúbrica, con un elemento evaluable por cada criterio de evaluación que recoge. Todas usan la [escala de niveles 0–4](/general/contenidos/3-evaluacion) del módulo.
