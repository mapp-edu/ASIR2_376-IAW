# 🎯 Resultados de aprendizaje y criterios de evaluación

El módulo tiene siete resultados de aprendizaje (RA). Cada uno se trabaja en una unidad de programación y tiene un peso en la nota final.

| RA | Resultado de aprendizaje | Peso | Unidad |
|:--:|:-------------------------|:----:|:------:|
| RA1 | Preparar el entorno de desarrollo y los servicios de aplicaciones web | 10 % | [UP1](/up1/) |
| RA2 | Implantar gestores de contenidos | 10 % | [UP2](/up2/) |
| RA3 | Administrar gestores de contenidos | 10 % | [UP3](/up3/) |
| RA4 | Gestionar aplicaciones de ofimática web | 10 % | [UP7](/up7/) |
| RA5 | Generar documentos web con lenguajes de guiones de servidor | 25 % | [UP5](/up5/) |
| RA6 | Generar documentos web con acceso a bases de datos | 25 % | [UP6](/up6/) |
| RA7 | Realizar modificaciones en gestores de contenidos | 10 % | [UP4](/up4/) |

## RA1 · Entorno y servidores de aplicaciones web (10 %)

**Preparar el entorno de desarrollo y los servicios de aplicaciones web instalando e integrando las funcionalidades necesarias.**

| CE | Criterio de evaluación |
|:--:|:-----------------------|
| 1a | Se ha identificado el software necesario para su funcionamiento. |
| 1b | Se han identificado las diferentes tecnologías empleadas. |
| 1c | Se han instalado y configurado servidores web y de bases de datos. |
| 1d | Se han reconocido las posibilidades de procesamiento en los entornos cliente y servidor. |
| 1e | Se han añadido y configurado los componentes y módulos necesarios para el procesamiento de código en el servidor. |
| 1f | Se ha instalado y configurado el acceso a bases de datos. |
| 1g | Se ha establecido y verificado la seguridad en los accesos al servidor. |
| 1h | Se han utilizado plataformas integradas orientadas a la prueba y desarrollo de aplicaciones web. |
| 1i | Se han documentado los procedimientos realizados. |

::: details Contenidos: instalación de servidores de aplicaciones web
- Análisis de requerimientos.
- Servidor web: instalación y configuración.
- Sistema gestor de base de datos.
- Procesamiento de código.
- Módulos y componentes necesarios.
- Comprobación del sistema.
- Utilidades de prueba e instalación integrada.
- Documentación de la instalación.
:::
